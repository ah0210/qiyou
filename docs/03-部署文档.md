# 栖游 · 部署文档

> 从零配置到真实上线的完整部署指引

## 一、本地自检（无需部署）

```bash
# 环境要求：Node ≥ 16（零 npm 依赖）
npm run all     # 一键全量检查：sync → check → audit → verify → test
```

各脚本单独运行：

| 命令 | 作用 |
|------|------|
| `npm run sync` | 端云同步 `_shared` 权威源 + diff 硬校验 |
| `npm run check` | 递归 `node --check` 全部 JS 语法 |
| `npm run audit:wx` | 微信运行期专项审计（Tab 跳转/switchTab 带参/页面四件套） |
| `npm run verify:pages` | usingComponents 组件引用校验 |
| `npm run verify:routes` | 跳转目标页面注册校验 |
| `npm run test` | 核心算法自测（19 项断言，含端云同构比对） |

## 二、微信开发者工具导入

1. 打开微信开发者工具 → 导入项目 → 选择本目录
2. AppID 已配置为 `wx201704fd7c00af5e`（可替换为测试号）
3. 若仅演示，保持 `miniprogram/config/env.js` 中 `cloudEnvId` 留空即可

## 三、开通云开发环境

1. 微信开发者工具 → 云开发 → 创建环境（记下环境 ID）
2. 编辑 `miniprogram/config/env.js`：
   ```js
   cloudEnvId: 'your-env-id'   // 替换为真实环境 ID
   ```
3. 编辑 `miniprogram/app.js`，在 `wx.cloud.init` 中确认使用 `env.cloudEnvId`

## 四、部署云函数（推荐顺序）

在微信开发者工具中，对 `cloudfunctions/` 下每个函数目录右键 →「上传并部署：云端安装依赖」。

推荐顺序（含依赖关系）：

```
1. login          # 登录与用户档案
2. city           # 城市列表（依赖 _shared/scoreCore + seedData）
3. house          # 房源列表（依赖 _shared/seedData）
4. seedData       # 种子数据导入（一次性）
5. aiMatch        # AI 旅居匹配（依赖 _shared/scoreCore + seedData）
6. aiChat         # AI 助手（依赖 _shared/seedData）
7. aiContract     # 合同筛查（依赖 _shared/riskCore + seedData）
8. family         # 家属绑定
9. community      # 同城问答
10. companion     # 兴趣结伴
11. policy        # 政策查询
12. analytics     # 埋点入库
```

> 注意：上传前请先运行 `npm run sync`，确保每个云函数的 `_shared/` 目录已是最新权威源。

## 五、初始化种子数据

部署 `seedData` 云函数后，在云开发控制台 → 云函数 → `seedData` →「测试」→ 传空参数触发一次，将种子数据（8 城市 / 8 房源 / 4 政策）写入 `cities` / `housings` / `policies` 集合（按 `_id` 幂等，可重复执行）。

## 六、配置 AI 密钥与环境变量

在云开发控制台为以下函数配置环境变量：

| 变量 | 作用 | 必填 |
|------|------|------|
| `TENCENT_SECRET_ID` | 腾讯云 API 密钥 ID（混元） | 启用 AI 时 |
| `TENCENT_SECRET_KEY` | 腾讯云 API 密钥 Key（混元） | 启用 AI 时 |
| `HUNYUAN_MODEL` | 混元模型名（默认 hunyuan-turbo） | 否 |
| `SOS_TMPL_ID` | 订阅消息模板 ID（SOS 推送） | 启用 SOS 时 |
| `AI_FALLBACK_ONLY` | 设为 `1` 强制走规则引擎（应急降级） | 否 |

## 七、开通语音插件（可选）

1. 小程序后台 → 设置 → 第三方设置 → 添加插件 `微信同声传译`（appid `wx069ba97219f66d99`，版本 0.3.6）
2. 未授权时，`utils/voice.js` 会自动捕获异常并降级为文字交互，不阻塞业务

## 八、开通订阅消息模板（SOS，可选）

1. 小程序后台 → 订阅消息 → 选用合适的「紧急呼叫通知」模板
2. 将模板 ID 填入 `family` 云函数环境变量 `SOS_TMPL_ID`

## 九、上线前检查清单

- [ ] `npm run all` 全绿

- [ ] `seedData` 已执行，集合有数据
- [ ] AI 密钥配置正确，`aiMatch` 返回 `model: 'hunyuan+rule'`（而非仅 `rule-v1`）
- [ ] 语音插件已授权（若启用）
- [ ] 订阅消息模板已配置（若启用 SOS）
