## 二、核心流程原型逻辑

### 流程 1：首次进入 → 身份选择 → 首页
```
启动 onLaunch（云初始化 + 状态恢复 + 静默登录）
   ↓ 未选身份
onboarding 页 → 选身份（nomad 数字游民 / traveler 短期旅居 / senior 康养长者）
   ↓ setRole + 持久化（senior 自动开启适老大字模式）
switchTab 首页 → 按身份渲染不同 HOME_MODULES
```

### 流程 2：AI 旅居匹配（核心）
```
首页「AI 旅居匹配」→ navigateTo packages/ai/match
   ↓ 用户填：预算 / 时长 / 身份 / 核心需求标签
调用 aiMatch 云函数 action=create
   ↓ 三段式引擎
硬筛（预算1.1弹性）→ 六维加权评分（权重随身份）→ Top3 城市 + 预算明细 + 政策 + 7日行程
   ↓ LLM 语言增强（不可用则模板兜底）
写 ai_plans 留痕 → 返回 planId
   ↓
navigateTo packages/ai/result?planId=xxx → 展示方案 + 雷达图 + 语音播报
```

### 流程 3：合同风险筛查
```
AI 助手 / 首页 → navigateTo packages/ai/contract
   ↓ 输入：粘贴文本 / 拍照上传（fileID）
调用 aiContract 云函数 action=analyze
   ↓ 规则引擎扫描（12 类风险）→ 可选 OCR → LLM 增强互校
风险列表（高/中/低三级 + 引用原文 + 修改建议）
   ↓ 写 contracts 留痕（仅本人可见）
展示合同报告（含"不构成法律意见"免责）
```

### 流程 4：语音问答（适老）
```
首页「语音问答」→ 长按 voice-fab 说话
   ↓ WechatSI ASR 识别（未授权降级文字输入）
voice.js routeCommand 识别指令 → 匹配路由表跳转
   ↓ 非指令 → globalData.pendingVoiceQuery 携带 → switchTab AI 助手
aiChat 云函数 → 场景化规则回复（医保/居住证/社保/预算/养老）
   ↓ TTS 分句朗读（插件单次≤100字排队）
```

### 流程 5：家属绑定 + 一键呼叫
```
养老工具箱 → navigateTo packages/senior/family
   ↓ 长辈生成 6 位邀请码（5 分钟有效）
家属输入邀请码 → accept 绑定（双向确认，不能绑自己）
   ↓
emergency 页 → makePhoneCall 一键呼叫 120/已绑定家属
```

## 三、状态流转（store.js 状态树）

```js
{
  role: 'traveler',        // nomad | traveler | senior
  theme: 'normal',         // normal | elder
  voice: { enabled, autoRead },
  userInfo, openid,
  familyBound, houseFilter, pendingVoiceQuery, lastPlan
}
```

- `setRole`：切换身份 + 持久化 + 云端 `updateProfile`（senior 自动开适老）
- `setTheme`：切换大字模式（通过根节点 class `.theme--elder` 生效）
- 页面通过 `pageBind({ dataKey: 'stateKey' })` 自动同步
