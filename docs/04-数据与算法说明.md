# 栖游 · 数据与算法说明

> 权威源集中管理，端云同构硬校验

## 一、单一权威源机制（`_shared`）

评分、合同、种子数据三类核心逻辑各有**唯一权威源**，位于 `cloudfunctions/_shared/`：

| 权威源 | 内容 | 分发目标 |
|--------|------|---------|
| `scoreCore.js` | 城市六维评分 + 旅居匹配 | 云函数 `aiMatch`/`city` + 端侧 `utils/match.js` |
| `riskCore.js` | 合同风险规则库（12 类） | 云函数 `aiContract` + 端侧 `utils/contract.js` |
| `seedData.js` | 种子数据（8 城/8 房源/4 政策） | 全部云函数 + 端侧 `mock/data.js` |

运行 `npm run sync` 后：
1. 将权威源**分发**到各云函数的 `_shared/` 子目录
2. **生成**端侧文件（带「自动生成，请勿手改」头）
3. 执行 **diff 硬校验**，确保端云算法完全一致

> 修改规则：**只改 `_shared/` 权威源，然后 `npm run sync`**，禁止手改分发产物。

## 二、城市六维评分（scoreCore）

### 六维定义

| 维度 | 含义 |
|------|------|
| cost | 物价友好 |
| medical | 医疗资源 |
| climate | 气候空气 |
| network | 网络办公 |
| senior | 养老配套 |
| life | 生活便利 |

### 身份权重（和恒等于 1）

| 身份 | cost | medical | climate | network | senior | life |
|------|------|---------|---------|---------|--------|------|
| nomad 数字游民 | .30 | .10 | .15 | .20 | .05 | .20 |
| traveler 短期旅居 | .30 | .10 | .20 | .10 | .05 | .25 |
| senior 康养长者 | .15 | .35 | .15 | .03 | .25 | .07 |

### 匹配算法（三段式）

1. **硬筛**：月成本 ≤ 预算 × 1.1（10% 弹性），需求标签为软约束（进评分，避免近义误剔除）
2. **评分**：`matchScore = 六维加权分 + 需求命中加分（每命中 +5，上限 +15）`，clamp [35, 98]
3. **方案**：Top3 城市 + 预算分项（分项求和 = 总额，防幻觉）+ 确定性理由

## 三、合同风险引擎（riskCore）

12 类风险规则，三级（高/中/低），每类含正则、原因、修改建议：

| 类型 | 级别 | 说明 |
|------|------|------|
| 押金退还 | 高 | 押金一律不退 |
| 押金金额 | 中 | 押金超过 1 个月 |
| 违约金 | 高 | 违约金比例畸高 |
| 转租限制 | 低 | 完全禁止转租 |
| 维修责任 | 高 | 维修全推给租客 |
| 租期涨租 | 中 | 房东可随时涨租 |
| 提前退租 | 中 | 退租即没收租金 |
| 口头承诺 | 中 | 重要事项依赖口头 |
| 人身伤害免责 | 高 | 免除安全保障责任 |
| 康养免责 | 高 | 康养机构免除照护责任 |
| 添附归属 | 低 | 装修添附无偿归房东 |
| 管辖地 | 低 | 争议管辖在房东所在地 |

### 合并策略

- 规则扫描：按 clause 切分，正则匹配 → 同类去重（保留最严重级别）
- LLM 语义扫描（可选增强）：强制输出 JSON，与规则结果 `mergeResults` 互校
- 摘要：高/中/低计数

> 免责声明：仅作风险提示，**不构成法律意见**。

## 四、种子数据（seedData）

- **8 城市**：大理、昆明、北海、成都、珠海、杭州、三亚、西双版纳
- **8 房源**：覆盖 nomad（游民公寓）/ wellness（康养）/ short（短租）三类型
- **4 政策卡**：异地就医、居住证、灵活就业社保、老年优待

所有数据标注 `dataSource: '公开统计资料人工整理'`，**仅供演示**，红线：禁爬虫。
